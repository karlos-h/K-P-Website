# Website Images

Store only optimized, website-ready images here.

Recommended formats:

- `avif` or `webp` for photographs
- `svg` for logos and simple graphics
- `jpg` as a compatibility fallback

Use descriptive lowercase names, for example:

- `hero/hero-crowd-01.webp`
- `events/rolling-meadows-2025-01.webp`
- `press/kava-pyramids-press-01.webp`

Do not place full-resolution camera originals in this folder.
